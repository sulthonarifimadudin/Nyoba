# Atelier Cahaya — Template Portofolio Foto

Template website portofolio fotografi dengan style **dark / hitam** yang lebih cinematic.

## Highlight desain

- Background hitam dengan aksen ungu-cyan glow
- Hero split layout + foto utama besar
- Grid koleksi ala masonry
- Kartu paket layanan + testimoni klien
- Fully responsive (desktop, tablet, mobile)

## Struktur file

- `index.html` — struktur section utama
- `styles.css` — styling tema dark, layout, dan responsif

## Jalankan lokal

```bash
python3 -m http.server 8000
```

Buka `http://localhost:8000`.

## Custom cepat

1. Ganti nama brand (navbar + footer).
2. Ganti URL foto di section koleksi.
3. Update harga paket dan testimoni.
4. Ubah warna tema di `:root` pada `styles.css`.
5. Ganti link WhatsApp/email di section kontak.
